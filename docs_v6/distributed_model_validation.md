# 分布模型 V6 外部验证

## 固定数据政策

校准仍只使用 4、8 m/s；5、6、10、12 m/s 和 Fig.10 继续作为固定验证集。没有重新数字化测试图、删除负面速度或修改冻结五节点参数。V6 重新运行所得结果与 V5 数值一致，主模型 SHA-256 更新为统一冻结值。

数值守恒和网格收敛通过，但物理外部验证失败。因此 50 节点模型仍是审计模型，不能作为五节点参考真值；五节点也没有通过独立高分辨率验证。

## 六项物理审计

1. Fig.7 色标两端均为红色，RGB 到温度的端点反演非唯一；保留原 V5 曲线和 ±1.5 K 不确定度，没有重新标色以降低误差。
2. Fig.2 单位确为 kg/s，100% 占空比同向与反向分别约 3.830e-4 和 2.226e-4 kg/s；现有稳态模型只使用同向曲线，换向流量物理不完整。
3. 2425.5 W/m² 对应单板、单电池还是等效堆面积无法从现有图像确定；拟合热量比例 0.13396 吸收了这一歧义。
4. 3962 mm² 与 COMSOL 等效单通道 82.333 mm² 相差 48.121 倍；Fig.7 风速到 Fig.2 占空比的线性映射不是论文直接给出的测量关系。
5. 稳态 4/8 m/s 数据不能辨识热容；厚度、自然对流、总 UA 和有效热量比例存在结构性混淆。
6. 当前换向模型没有死区、有限空气驻留时间或传感器热惯性；这些参数不能用固定验证集 Fig.10 反向拟合。

拟合参数、边界、来源与可辨识性逐项记录于 `outputs_v6/distributed_model/physical_audit_v6.json`。由于核心尺度仍不可辨识，本轮没有采用未经证实的“修正”把验收改为通过。
