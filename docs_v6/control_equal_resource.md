# Hotspot-MPC V6 等资源比较

## 搜索范围

临界工况完整扫描了 1,152 个组合：

- `fan_weight`: 1, 2, 5, 10, 20, 50；
- `hotspot_weight`: 0.5, 1, 2, 4；
- `gradient_weight`: 0.2, 0.5, 1, 2；
- `minimum_dwell_s`: 10, 30, 60；
- `direction_switch_weight`: 1, 4, 10, 30。

最大占空比步长由 V5 的 0.15 收紧到 0.05。所有点使用同一临界轨迹、噪声 seed、冻结模型和 AuthorMeasured-PI-SMC 基线。

## 等能耗冻结点

共找到 173 个与基线风扇能耗差在 ±5% 内的点。按该子集内热点 RMSE、温差 RMSE、换向次数依次排序后冻结的点，能耗差为 +4.541%。这是真正的等能耗点，不再使用 V5 相差 42.24% 的最近点冒充。

| 临界工况指标 | 冻结 MPC 相对 PI-SMC |
|---|---:|
| 最大热点绝对下降 | -2.008°C（即升高 2.008°C） |
| 高于 55°C 的 RMSE 改善 | -146.62% |
| 温差 RMSE 改善 | -342.43% |
| 风扇能耗变化 | +4.541% |
| 换向次数变化 | -24 |
| 平均温度跟踪 RMSE 变化 | +104.08% |

因此 Hotspot-MPC 在 ±5% 等能耗下没有优势。

## 全部可行场景

冻结点用于标称、临界、模型失配、纯噪声、预览 -10% 和环境 +5°C 场景的四控制器比较；执行器受限场景仍单独标记为不可行，不进入正常聚合。聚合能耗差为 -1.27%，但 MPC 最大热点高 1.826°C，高于 55°C 的 RMSE 恶化 175.58%，温差 RMSE 恶化 328.41%，平均温度跟踪 RMSE 恶化 46.18%。

相同 10 s 驻留、换向次数仅相差 2 次的临界比较同样失败：MPC 最大热点高 4.938°C，高于 55°C 的 RMSE 恶化 409.62%。

55°C 在所有计算中仅为参考温度，不是安全温度。Hotspot-MPC 应从核心创新降级为负面比较或待重新设计方法。
