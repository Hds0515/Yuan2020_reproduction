# 门控 MM-EKF V6 验证

## 固定测试集

V6 直接读取 V5 的 `continuous_off_grid_100x10.csv` 作为对象与 seed 注册表，保持 100 个库外对象、每对象 10 个噪声 seed、共 1,000 对样本。传感器节点仍为 1 和 5，模型库和所有测量随机数均未重抽。

## 门控实现

门控 MM-EKF 同时保留名义单模型滤波器，并加入：

- 基于持续超额 NIS 的创新显著性门控；
- 归一化概率熵与最大概率联合门控；
- 0.005 模型概率下限；
- 每步只吸收 35% 新后验的概率塌缩速率限制；
- 门控关闭时直接回退到名义单 EKF。

## 验收

| 指标 | V5 | 门控 V6 | 门槛 | 通过 |
|---|---:|---:|---:|:---:|
| 改善样本比例 | 84.5% | 86.7% | >50% | 是 |
| 中位改善 | 14.24% | 41.07% | >10% | 是 |
| 配对均值 95% CI | [31.88%, 36.06%] | [37.50%, 41.40%] | 下界>0 | 是 |
| 标称中位损失 | 3.53% | 0.00% | <5% | 是 |
| 纯噪声中位损失 | 5.81% | 0.00% | <5% | 是 |

四项数值门槛全部通过。在标称和纯测量噪声审计中，证据门控保持关闭，因此估计等同于单 EKF。

该门控是在看到 V5 失败模式后提出的后验改进；虽然评估严格复用了固定 V5 测试集，论文中仍应明确标注开发顺序，并最好增加新的预注册确认集。当前可将其作为“固定压力测试下通过”的核心候选，而不能写成对任意噪声和任意对象都一致优越。
