# COMSOL 6.4 本机验证

## 结论

本机 COMSOL 6.4.0.293 已实际编译和运行三个 Stage 1 Java 模型。选择审计、0.1 m/s 默认流动求解以及规定速度共轭传热均通过各自数值门槛。该结论替代 V5“网页环境未运行 COMSOL”的状态，但不等同于复现论文原始三维几何。

入口、出口均恰好为一个边界，选择门控通过。

## 默认流动求解器

`Stage1DefaultSolver.java` 只调用 COMSOL 生成的默认求解器树，没有手写 Fully Coupled 节点。二次速度/一次压力离散的结构化扫掠网格在 0.1 m/s 下收敛：

| 指标 | 结果 |
|---|---:|
| 通道入口质量流量 | 9.24619e-6 kg/s |
| 通道出口质量流量 | 9.24505e-6 kg/s |
| 质量不平衡 | 0.01230% |
| 压力范围 | 0–6.44753 Pa |

质量不平衡低于 0.1%，完整流动门槛通过。早期一次离散和自由四面体诊断分别出现 3.11% 与 6.08% 不平衡，仅保留为失败诊断，未用于通过结论。

## 规定速度传热

COMSOL 6.4 API 已确认 `HeatTransferInSolidsAndFluids` 的流体域可使用 `u_src=userdef` 和速度向量 `{uin,0,0}`。模型包含空气和石墨材料、25°C 入口、2425.5 W/m² 固体热流、三区域平均算子、热点坐标、空气出口温度和完整能量账本。

采用嵌套结构化扫掠网格：粗 2,160、中 17,280、细 64,800 单元。4、5、6、8、10、12 m/s 均收敛。中—细 `Tmax` 相对差为 0.0054%–0.0826%，三区域最大绝对差为 0.0182–0.1022°C，细网格最大相对能量误差为 1.11e-13；三项均优于 1%、0.2°C 和 0.5% 门槛。
