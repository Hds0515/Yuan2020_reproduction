完成了 V2 完整性审计、受保护输入哈希清单、从原 JPG 出发的曲线数字化、两候选热源模型的多起点加权辨识、预声明独立验证、局部协方差/相关性与 bootstrap、显式能量收支三节点模型、一键 Python 复现入口、五节点能量一致性、全传感器组合 EKF、多模型观测器，以及七场景三控制器比较。11 项自动测试全部通过。

## 2. 三节点结果

- Fig14 校准 RMSE：0.249137 °C；
- Fig16 0–700 s 校准 RMSE：0.250632 °C；
- Fig16 700–1200 s 独立验证 RMSE：0.296047 °C；

验证段从未加入参数目标函数。模型 A（热中性电压—代理电功率）按预声明验证比较胜出；模型 B 虽可校准，但独立验证 RMSE 更差。极化曲线只是可重复代理，不是作者完整电化学模型。

## 3. 可辨识性

冻结参数为 C=4381.6002 J/K、Kcool=31.72247 W/K、Knode=7.183329 W/K、Kp=0.072717 1/K、Ki=0.0014992 1/(K·s)。加权雅可比条件数 1.836e9；Kcool–Kp 相关系数约 0.9999995，C–Knode 约 0.99999994。没有风机占空比观测时，Kcool、Kp、Ki 在闭环中结构性纠缠，应优先报告 Kcool·Kp=2.30676 和 Kcool·Ki=0.0475585，而不是把单个参数当作高精度物理测量。8 次 bootstrap 只足以证明流水线可运行，论文发表前应增至至少 200 次。

## 4. COMSOL

Java 编译：成功。稳态求解：失败。最后安全中止点是 Stokes 初始化分离求解在 12% 处持续振荡。因无收敛解，网格收敛、CFD 能量守恒、温度云图、六风速区域温度、稳态/瞬态交叉验证全部未完成，报告中没有任何伪造数值。

## 5. 五节点与观测器

三/五节点平均温度 RMSE 0.00449 °C，五节点最大能量残差 1.18e-11 W。推荐两传感器位置为节点 2、5。多模型 EKF 热点 RMSE 0.04674 °C，单模型为 0.05115 °C，改善约 8.6%，但证据仅限模拟。

## 6. 控制比较

MPC 使用 EKF 估计状态，并满足 duty 范围、0.1/步变化率和 10 s 流向驻留约束。相对论文式中点 PI–SMC，七场景聚合热点越界 RMSE 从 2.1079 降至 1.7282 °C，平均温差从 0.4138 降至 0.1243 °C，风机能耗代理增加约 14.5%。执行器受限案例被单独标记为不可行，输出最大散热，不引入主动限载。

## 7. 论文支撑程度

当前足以支撑硕士论文中的：公开曲线复现方法、低阶模型辨识与可辨识性讨论、观测器和 MPC 的仿真方法章节。它还不足以支撑“等效三维模型已验证”“控制策略经 CFD 或实验验证”或“参数具有唯一物理意义”等强结论。

## 8. 仍不能声称

- 不能称为开放阴极反应空气—冷却空气耦合模型；
- 不能推断氧传输、水淹或膜含水量；
- 不能称 COMSOL 几何为作者精确原模型；
- 不能声称 COMSOL 网格/能量/交叉验证通过；
- 不能把代理极化曲线当作作者完整电化学模型；
- 不能把模拟中的 MPC 优势直接外推为实验性能。
