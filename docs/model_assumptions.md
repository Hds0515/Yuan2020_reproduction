# 模型假设与参数来源边界

## 论文直接给定或直接可读

- 40 个电池；最佳/参考温度 55 °C。
- 风扇在 Fig14 中由中间节点达到 53 °C 后启用。
- SMC 温差阈值 0.5 °C，工作频率 0.1 Hz，即更新周期 10 s。
- 三个冷却空气节点温度 24.8、30.05、35.3 °C。
- 堆质量 10.5 kg；论文没有直接给出本复现所需的总有效热容。
- 3D 模型材料参数、入口温度 25 °C、热流密度 2425.5 W/m²、入口速度 4/5/6/8/10/12 m/s。
- 控制模型入口总截面积 3962 mm²、节点控制体截面积 1420 mm²、活性面积 247 cm²。

## v3 辨识参数

- `C_th`、`K_cool`、`K_node`、`Kp`、`Ki` 只使用 Fig14 0-1200 s 与 Fig16 0-700 s 的 regenerated 曲线辨识。
- Fig16 700-1200 s 不参与优化，只用于附件预先规定的独立验证和热源 A/B 比较。
- 冻结参数和局部/Bootstrap 区间见 `identification_v3/`。

## 热源模型

模型 A 使用 `Qgen = 40 I 1.253 - Vstack I`。其中 1.253 V 是热中性电压，`Vstack` 来自可重复的低阶极化代理；它不是 Yuan 等人的完整电化学模型，不能用来推导膜含水量、氧传输、水淹或局部反应分布。

模型 B 使用只在校准集辨识的 `a0 + a1 I + a2 I²`。两套模型冻结后，模型 A 的独立验证 RMSE 为 0.2960 °C，模型 B 为 0.3253 °C，因此 v3 冻结模型 A。这个选择并不把论文最终曲线硬编码进模型。

## 控制导向热模型假设

- 三节点总热容均分到各节点；产热均匀分配。
- 只建模独立空气冷却流道方向；反应气体热输运、辐射和外表面对流在三节点辨识模型中忽略或吸收到有效参数。
- 相邻节点用线性有效导热系数连接。
- 冷却项只在堆温高于相应冷却空气温度时生效。
- PI 使用条件积分抗饱和；数值积分为显式 Euler，时间步为显式输入。

## COMSOL 等效几何假设

论文未提供原 CAD、通道数量、完整板厚、接触热阻和外表面对流系数，因此只能建立 `Yuan2020_equivalent_3D`。247 cm²、3962 mm² 与 1420 mm² 的物理含义分开记录，不能同时当作同一块几何面的精确尺寸。COMSOL 调整参数不得回写三节点冻结参数。
