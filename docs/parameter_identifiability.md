# 参数可辨识性结论

## 数值结果

冻结热源模型 A 的加权雅可比条件数为 `1.84e9`，表明当前公开曲线不足以唯一确定所有五个参数。局部相关矩阵中：

- `corr(K_cool, Kp) = 0.9999995`，几乎完全正相关；
- `corr(C_th, K_node) = 0.99999994`，也出现近共线；
- `Ki` 在该局部线性化点与 `K_cool` 的相关系数不高，但其 bootstrap 区间较宽，且在未公开占空比的闭环中仍与冷却增益结构性耦合。

## 为什么 Kcool、Kp、Ki 不能分别当作物理真值

在线性未饱和区，冷却项近似为：

`K_cool [Kp (T-Tref) + Ki integral(T-Tref)] (T-Tcool)`。

温度曲线主要约束的是 `K_cool*Kp` 与 `K_cool*Ki`。没有论文风扇占空比时序，就缺少把风扇增益和控制器增益分开的独立观测。饱和、启停与 SMC 非线性会让某个局部相关系数看似下降，但不会消除这一结构性信息缺失。

冻结有效乘积为：

- `K_cool*Kp = 2.30676 W/K²`
- `K_cool*Ki = 0.0475585 W/(K² s)`

## 置信区间解释

局部协方差由数值雅可比给出，但模型包含风扇启停、饱和与离散 SMC，目标函数并非处处光滑；因此局部区间会异常窄，不能单独作为可信不确定度。v3 另外执行 8 次固定种子的 30 s 块 bootstrap。受运行时间限制，8 次只够证明流程与暴露不稳定性，不足以形成发表级尾部分位数；论文定稿前应把配置中的 bootstrap 次数提高到至少 200，并报告运行环境与耗时。

## 可声称与不可声称

可以声称：存在一组冻结名义参数，在严格分离验证下达到 0.2960 °C RMSE，且有效闭环乘积受曲线约束。

不能声称：`K_cool`、`Kp`、`Ki` 或 `C_th`、`K_node` 的单独数值是唯一物理真值，也不能用局部窄区间掩盖 1.84e9 的病态条件数。
