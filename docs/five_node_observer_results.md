# 五节点模型与状态观测器结果

五节点模型是独立能量方程，不是把三节点温度插值后冒充模型。离散时保持总热容 4381.6002 J/K、总产热和总冷却面积不变；相邻节点导热按网格间距修正。插值只用于构造共同初始条件。

## 三节点—五节点一致性

在相同负载、风机占空比和流向下：

- 平均温度 RMSE：0.0044899 °C；
- 热点温度 RMSE：0.0224409 °C；
- 最大绝对能量残差：1.1816e-11 W；
- 冷却面积保持比：1.0。

详细时间序列在 `outputs/five_node/three_vs_five_node_consistency.csv`。

## EKF 与传感器位置

对 1、2、3 个传感器的所有节点组合进行了系统穷举，并覆盖标称、测量噪声、热容 +12%、冷却增益 −15%、导热 +20% 和负载预报 −10% 六类场景。评价包含五个节点 RMSE、热点 RMSE、热点位置准确率、最大误差和 95% 绝对误差分位数。

跨场景平均热点误差选出的两传感器位置为节点 2 和 5，平均热点 RMSE 0.0680512 °C。位置选择基于所有预声明场景的聚合结果，而非挑选单一案例。

## 多模型观测器

在同一两传感器位置和同一测量序列上：

- 单模型 EKF 平均热点 RMSE：0.0511545 °C；
- 多模型 EKF 平均热点 RMSE：0.0467391 °C。

多模型方法在该仿真集合中有约 8.6% 的平均改进，属于小幅改善而非压倒性优势。它仍需要实验数据验证，不能直接作为已证实的工程创新。
