# COMSOL V7 参数来源审计

## 论文 Table 2 直接给定参数

| 材料 | 参数 | V7 数值 | 单位 |
|---|---|---:|---|
| graphite | 导热率 `k` | 24 | W/(m·K) |
| graphite | 比热 `Cp` | 460 | J/(kg·K) |
| graphite | 密度 `rho` | 2250 | kg/m³ |
| air | 导热率 `k` | 0.0251 | W/(m·K) |
| air | 比热 `Cp` | 1007 | J/(kg·K) |
| air | 密度 `rho` | 1.184 | kg/m³ |
| air | 动力黏度 `mu` | 1.849e-5 | Pa·s |

V6 中石墨 `k=150 W/(m·K)`、`Cp=710 J/(kg·K)`、`rho=1800 kg/m³` 已在 V7 模型中全部禁止使用。空气导热率由 0.0257 修正为 Table 2 的 0.0251 W/(m·K)。

## 文献补充参数

本轮没有用外部文献替换 Table 2 材料参数。空气动力黏度仅用于完整流场；规定速度热模型不通过黏度反推质量流量。

## 等效几何假设

- 选择解释 C：一个等效通道代表一个电池，40 个通道并联。
- 等效空气层厚度固定为 1 mm；由单电池入口面积 99.05 mm² 得到宽度 99.05 mm。
- 单电池受热面积保留为 0.0247 m²，因此等效流向长度为 249.369 mm。
- 固体厚度保留为 10 mm。该尺寸是等效几何假设，不是 Table 2 材料参数。

## 校准参数

仅允许使用 4、8 m/s Fig.7 数据校准：

- 外表面自然对流换热系数 `h_external`；
- 表面发射率 `emissivity`。

边界分别限制为 `0 ≤ h_external ≤ 30 W/(m²·K)`、`0 ≤ emissivity ≤ 1`。热流密度、入口面积、材料参数、固体热容和单电池热流面积均保持冻结。

## 未知参数

- 原论文外表面真实自然对流条件；
- 表面涂层/氧化状态对应的真实发射率；
- 支撑结构接触面积和接触导热；
- 原始三维通道、肋片和歧管几何；
- Fig.7 规定速度与 Fig.2 风扇占空比之间的实验转换关系。

V7 不使用未知支撑导热作为额外拟合自由度。若仅靠允许的两个外部散热参数不能通过独立风速验证，则保留失败结论。
