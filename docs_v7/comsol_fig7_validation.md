# V7 COMSOL Fig.7 独立验证

## 决策

修正后的模型在 COMSOL 6.4 中数值收敛，但没有通过 Fig.7 物理外部验证。其状态只能标记为 `numerically_converged`，不得标记为 `physically_validated`。

## 冻结设置

- Table 2 石墨参数：`k=24 W/(m·K)`、`Cp=460 J/(kg·K)`、`rho=2250 kg/m³`。
- Table 2 空气参数：`k=0.0251 W/(m·K)`、`Cp=1007 J/(kg·K)`、`rho=1.184 kg/m³`、`mu=1.849e-5 Pa·s`。
- 尺度解释 C：`3962 mm²` 是整堆入口，40 个并联代表通道，每通道 `99.05 mm²`。
- 单电池受热面积 `0.0247 m²`，热流 `2425.5 W/m²`，单电池输入 `59.90985 W`。
- 环境温度 25°C；加入自然对流和表面辐射，不使用支撑导热自由度。
- 只用 4、8 m/s 校准 `h_external` 和 `emissivity`；5、6、10、12 m/s保持独立。

## 数值结果

校准在允许边界上得到 `h_external=30 W/(m²·K)`、`emissivity=1.0`，两者都顶到上界，这是模型结构仍不充分的警告。六风速、粗/中/细三套网格都求解完成：

- 中—细网格最大 `Tmax` 相对差：0.00840%（门槛 1%）；
- 中—细三区域最大温差：0.04418°C（门槛 0.2°C）；
- 最大能量残差：0.02794%（门槛 0.5%）；
- 温度范围与 Fig.7 色标量级一致。

## 物理外部验证

- 4、8 m/s 校准集三区域平均 RMSE：4.012°C；
- 5、6、10、12 m/s独立集三区域平均 RMSE：4.685°C；
- 独立风速最坏 RMSE：6.881°C；
- 独立门槛：每个独立风速 RMSE ≤1.5°C，未通过；
- 热点位置趋势 Spearman 相关：0.154，未通过趋势一致性判断。

因此六张云图只证明求解流程、网格与能量账本可运行，不能作为可信 Fig.7 复现图使用。完整逐风速数据见 `outputs_v7/comsol_fig7_validation.csv`。

## 门控后果

高分辨率瞬态参考数据集、五区域 ROM、门控 MM-EKF 新确认集、Oracle MPC 和分层闭环实验均不得启动。失败场景和固定验证风速未被删除，也未放宽验收标准。
