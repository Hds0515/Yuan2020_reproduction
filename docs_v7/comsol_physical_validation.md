# V7 COMSOL 物理验证总报告

## 完整流场

`Stage2PhysicalFlow.java` 在 COMSOL 6.4.0.293 编译并使用软件生成的默认稳态求解器。入口和出口各选中一个边界；入口以与 `rho*u*A` 相同的质量流量条件施加，避免速度入口剖面导致平均流量偏差。

0.1 m/s 结果：

| 指标 | 结果 | 门槛 | 判定 |
|---|---:|---:|---|
| 单通道入口质量流量 | 1.17275199746e-5 kg/s | `rho*u*A=1.172752e-5` | 通过 |
| `rho*u*A` 相对误差 | 2.17e-9 | <0.1% | 通过 |
| 进出口质量不平衡 | 0.003475% | <0.1% | 通过 |
| 压力范围 | 0–5.622 Pa | 报告项 | 已报告 |

完整流动数值收敛并通过质量守恒门槛。精确机器可读结果见 `outputs_v7/comsol_flow_validation.json`。

## 规定速度热模型

`Stage2PhysicalHeat.java` 使用 Table 2 固定材料、同一入口/质量流量/热量尺度，以及外表面对流和辐射。4、5、6、8、10、12 m/s均收敛，网格与能量门槛全部通过，但 Fig.7 独立 RMSE 和热点趋势门槛失败。

最终判定：`numerically_converged=true`，`physically_validated=false`。参见 `docs_v7/comsol_fig7_validation.md`。

## 云图使用限制

已经生成六张固定色标的固体表面温度云图，但由于物理外部验证失败，不得在论文中作为经过验证的温度证据。55°C在所有报告中仅称为参考温度，不称为安全上限。
