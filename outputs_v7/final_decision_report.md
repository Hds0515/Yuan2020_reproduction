# V7 最终决策报告

## 总结

V7 在本机 COMSOL 6.4 中修正了 Table 2 材料参数，统一采用“整堆 3962 mm²、40 个并联代表通道”的唯一尺度解释，并加入外部自然对流和辐射。完整 0.1 m/s 流场通过默认求解器与质量守恒门槛；六风速热模型通过求解、网格和能量门槛，但没有通过固定 Fig.7 外部验证。

由于物理验证是硬门控，后续高分辨率瞬态参考集、五区域 ROM、V7 门控 MM-EKF 确认集和 Oracle MPC 决定性实验均未执行。这是对预注册顺序的遵守，不是把未运行项目记为通过，也不是把它们的性能记为数值失败。

## 十二项回答

1. **修正 COMSOL 是否物理匹配 Fig.7：否。** 独立风速三区域平均 RMSE 为 4.685°C，最坏为 6.881°C，热点位置 Spearman 相关为 0.154；门槛分别为 ≤1.5°C和趋势一致。只可标记为数值收敛。
2. **高分辨率瞬态模型是否可信：否。** 因上游物理门控失败而未建立，不能将旧网页 50 节点模型替代为可信真值。
3. **五区域模型是否通过独立高保真验证：否。** 新模型未辨识，旧五节点模型未复用；准确语义是 `not_evaluated`，不存在通过主张。
4. **门控 MM-EKF 是否通过预注册确认集：否。** 预注册框架已冻结，但新的高保真确认集不存在，实验未运行。V6 后验开发结果仍保留为候选证据。
5. **Oracle MPC 在无资源匹配下是否有效：未评估。** 三个前置条件未满足。
6. **Oracle MPC 在等风扇能耗下是否优于 PI：未评估。** 没有合法 V7 等能耗搜索，不能沿用旧模型结果。
7. **Oracle MPC 在等换向预算下是否优于 PI：未评估。** 同最小驻留时间与换向次数约束实验均未运行。
8. **联合资源预算下是否仍有优势：未评估。** 不存在可报告的联合预算点。
9. **控制失败来自模型、观测器还是物理执行能力：目前不能归因。** 实验在 Level 1 之前被 COMSOL 物理门控阻断；不能把它解释为 MPC、ROM 或观测器失败。
10. **控制创新是否保留：不作为当前受支持创新保留。** 原因是决定性实验未获授权，而不是 Oracle 已被证明无效。后续只有从物理模型重新通过门控后才能重新审议。
11. **最终两个创新点是什么：本轮无法诚实确定两个已完全支持的创新点。** 门控 MM-EKF仍是需要新确认集的候选；新的物理验证五区域 ROM 尚不存在。Table 2 一致的 COMSOL 质量/能量/网格审计是可复现的方法学与负面结果，不提升为已经物理验证的模型创新。
12. **是否可开始撰写最终结果章节：不可定稿。** 可以撰写材料/尺度修正、数值收敛和 Fig.7 外部验证失败的受限结果章节，但不能撰写 ROM、观察器确认或 Oracle MPC 的正面最终结论。
