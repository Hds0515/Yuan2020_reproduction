# V10 Python / COMSOL 独立实现审计

## 控制方程

代表通道采用沿流向一维守恒方程：

\[
-\frac{d}{dx}\left(kA\frac{dT_s}{dx}\right)
+hP(T_s-T_a)=\frac{Q_{cell}}{80L},
\]

\[
\dot m C_p\frac{dT_a}{dx}=hP(T_s-T_a),\qquad
\dot m=\rho u A_{ch}.
\]

固体两端使用零轴向热通量，空气入口为 21°C。每个代表通道输入严格等于 `Qcell/80`；空气焓升由同一个界面热流产生，没有重复面积缩放。Python 采用守恒控制体离散，COMSOL 6.4 采用 General Form PDE 和默认稳态求解器。
