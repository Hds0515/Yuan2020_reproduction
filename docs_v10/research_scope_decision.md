# 研究方向与后续模型选择判定

## 当前可以合理改变什么

可以改变研究基线和物理模型，但必须把它作为新模型声明，并满足来源、冻结、校准/验证隔离和负面结果保留。V10 已按这一规则执行：没有修改 V9 四参数，没有用 Table 1 温度拟合新参数，也没有把代表通道伪装成 Yuan 原始 CAD。

后续可合理引入的物理项包括：

- 可审计的多通道与入口/出口 plenum；
- 局部电流密度决定的非均匀热源；
- BPP–GDL 接触热阻及压紧力范围；
- 温度相关空气物性；
- 经独立实验或文献范围约束的外部散热；
- 真实风扇曲线和逐通道流量分配。

每次最多只校准少量、具有单一物理含义的干扰参数，并继续保留独立确认集。

## 当前不允许什么

- 不允许把工况 1 从完整门槛中删除；
- 不允许通过调 `Nu`、热量、入口面积或通道数消除 19.4°C 误差；
- 不允许把 V10 称为已验证的完整堆/歧管 CFD；
- 不允许用 V10 当前一维温度场训练“高保真”ROM 或做决定性 MPC 优越性结论；
- 55°C 仍只可称为参考温度。

## 推荐的可执行替代路线

若研究重点必须是“多区域模型 + 观测器 + 控制”，最稳妥的下一步是选择代码和算例公开的高保真基线，而不是继续增加 V10 自由参数。候选包括：

1. [OpenFOAM 三维非等温 PEMFC 模型与公开算例](https://journal.openfoam.com/index.php/ofj/article/view/50)，可审计源项和流场；
2. [OpenFCST](https://openfcst.org/) 的开源燃料电池仿真框架；
3. [开放的两相 PEMFC 数值模型](https://www.sciencedirect.com/science/article/pii/S0010465518302807)，用于更完整的水热耦合；
4. 若必须研究歧管不均匀性，使用有明确多通道/歧管结构的[流量分配研究](https://www.sciencedirect.com/science/article/pii/S0196890419312622)作为结构依据。

新基线必须先完成稳态实验、空间温度、能量守恒和瞬态确认，然后才能冻结 50 区域数据集。若只能获得自洽数值模型而没有独立实验，应将结论限定为“仿真基准上的方法比较”，不能写成实物系统已验证。

## 当前闸门

- 代表通道机理研究：允许；
- 探索性 ROM/控制器代码调试：可另立分支，但不得形成性能主结论；
- 正式五区域 ROM 独立高保真确认：不允许；
- MM-EKF 预注册确认与 Oracle MPC 决定性实验：不允许；
- 最终结果章节：可以写 V7–V10 的复现失败、可辨识性和模型结构限制章节；控制创新的正面结论章节尚不能开始。
