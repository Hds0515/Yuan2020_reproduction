# 观测器决定性验证

## 设计
- 100个连续库外Latin hypercube真实对象；
- 每个对象10个噪声seed，共1000个配对样本；
- 传感器仅在独立设计集选择；
- exact-in-bank、leave-one-out、标称和纯噪声补充审计；
- 快速线性化：产热在55°C求值，冷却/导热在线性温区内保持精确。

## 结果
- 传感器节点：[1, 5]
- 中位热点RMSE改善：14.24%
- 平均改善：34.00%
- 改善样本比例：84.5%
- 最坏改善：-16.82%
- 配对95%CI：[31.88%, 36.06%]
- 标称中位性能损失：3.53%
- 纯噪声中位性能损失：5.81%

## 预设门槛
| 条件 | 结果 |
|---|---|
| 库外多数改善 | True |
| 95%CI下界>0 | True |
| 中位改善>10% | True |
| 标称和纯噪声损失均<5% | False |

**结论：MM-EKF尚未通过全部核心创新门槛。** 纯噪声损失为5.81%，略高于5%，且存在退化样本。目前应定位为有潜力的扩展方法。
