# V8 Fig.7 数字化复核

## 结论

Fig.7 自动数字化在当前用途下可靠，不触发重新数字化。72个人工固定点（每个速度、每个区域4点）与自动三区域结果的总体 RMSE 为 **0.662°C**，各速度中最大区域 RMSE 为 **0.858°C**，均低于1°C触发线。原有5、6、10、12 m/s验证目标和1.5°C验收门槛保持不变。
