# V8 冷却结构模型选择

## 模型定义

- **M0**：V7连续1 mm空气层失败基线；保留其 `h_external=30`、`emissivity=1` 上界补偿，仅用于比较。
- **M1**：H3多矩形通道，显式湿周、石墨肋、水力直径和接触面积；自由参数2个。
- **M2**：`h_forced=h0(u/8)^m` 与空气沿程焓升耦合；固定几何 `P_eff=0.09905 m`，只校准 `h0` 和 `m`。

所有模型只用4、8 m/s校准，5、6、10、12 m/s保持固定验证。

M2在AICc/BIC和独立区域温度上最好，但仍远高于1.5°C门槛。M1/M2预测的沿程温差约0.5–1.2°C，而Fig.7为约8–11°C；两者热点都固定在出口，无法复现热点位置趋势。M1还把等效水力直径推到30 mm上界。

## 数值门槛

M1/M2能量残差均低于 `2.5e-14`，中—细网格Tmax相对差低于 `1.5e-6`，三区域最大差低于0.0041°C；空气冷却份额随风速单调增强。因此失败不是数值收敛或守恒问题，而是结构表达和缺失几何信息问题。

## 停止决定

M1和M2均未通过，停止Fig.7精确复现，不再增加自由参数。没有模型结构被选中或生成“通过模型”SHA-256。Thermal文章只保留为三节点实验基线和定性结构参考，不再作为高保真空间基线。

建议替代方案：优先建立具有完整CAD、通道尺寸、热流作用面、风机压流曲线和原始空间温度数据的自有共轭传热基准；若采用公开文献数据，只接受同时发布几何/网格、边界条件和原始验证数据的基准，而不再从单张温度云图反演高保真真值。
