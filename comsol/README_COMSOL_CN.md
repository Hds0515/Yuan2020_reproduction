# COMSOL 6.4 等效三维冷却通道模型

## 已完成

- 已提供参数化 Java API 建模脚本 `Yuan2020Equivalent3D.java`。
- 已写入论文公开的材料与边界参数：
  - 石墨导热系数 24 W/(m·K)；
  - 石墨比热 460 J/(kg·K)；
  - 石墨密度 2250 kg/m³；
  - 空气导热系数 0.0251 W/(m·K)；
  - 空气比热 1007 J/(kg·K)；
  - 空气密度 1.184 kg/m³；
  - 热流密度 2425.5 W/m²；
  - 入口温度 25 °C；
  - 入口速度 4、5、6、8、10、12 m/s。
- 已建立入口、中部、出口三个固体区域平均温度输出。
- 已提供 `validate_comsol_reduction.py` 和 CSV 模板。

## 当前未执行的部分

本运行环境没有 COMSOL，因此不能生成或求解 `.mph`，也不能声称已经得到 COMSOL 数值结果。
脚本针对用户已有的 COMSOL 6.4 编写，但首次运行时仍应核对自动生成的几何选择名称。

## 为什么只能叫“等效模型”

论文没有公开完整的通道尺寸、数量、板厚、外表面对流系数、接触热阻和原始 CAD。
脚本采用满足 247 cm² 有效面积和 3962 mm² 总入口面积的均质化通道，因此用于：

1. 检查沿流向温度梯度趋势；
2. 输出三个区域温度；
3. 进行三节点降阶交叉验证；

不能用于宣称精确恢复论文图 7 的原始几何。
